# Portfolio de Fotografia

Site estático pronto para publicar na Vercel.

## Como editar

- Troque o nome `Lumière Studio` pelo nome real do fotógrafo ou estúdio.
- Substitua as URLs de imagens do Unsplash em `index.html` pelas fotos reais do portfólio.
- Atualize o WhatsApp em `https://wa.me/5592999999999`.
- Atualize o e-mail `contato@lumierestudio.com`.
- Ajuste cidade, serviços, depoimentos e textos conforme o projeto final.

## Publicar na Vercel

1. Envie estes arquivos para o repositório no GitHub.
2. Na Vercel, clique em `Add New Project`.
3. Importe o repositório.
4. Framework Preset: `Other`.
5. Build Command: deixe vazio.
6. Output Directory: deixe vazio ou use `.`.
7. Clique em `Deploy`.

Depois do deploy, conecte o domínio da Hostinger em `Project Settings > Domains` na Vercel e configure o DNS conforme as instruções exibidas.
